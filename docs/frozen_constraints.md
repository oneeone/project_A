# 已冻结约束与待确认项

## 1. 已冻结的数据事实

1. 样本编号为1001至2000，共1000组。
2. 配对规则为文件名末尾数字编号一致。
3. 光学数组尺寸为256×256×4，uint8。
4. SAR数组尺寸为256×256，uint8，极化方式为HH。
5. 标签数组尺寸为256×256，uint8，实际像素值只有0和1。
6. 三类数据数组尺寸完全一致。
7. 主办方训练数据使用WGS 84地理坐标。
8. 模型基础输入为4个光学通道和1个SAR通道，共5通道。
9. SAR已经转换为0至255图像值，不得再次盲目转换为dB。
10. 问题1使用原始256×256数组训练，不按异常标签地理元数据拉伸标签。
11. 面积不能按经纬度差直接计算。
12. 训练、验证和测试必须按空间块划分。

## 2. 标签解释

标签1区域的平均SAR灰度显著低于标签0，且可视化显示已有河道多未标记、灾后扩张低散射区域被标记。当前统一解释：

- 0：非新增淹没区。
- 1：新增淹没目标。
- 其他值：忽略。

附件没有独立README明确标签语义，因此论文中应说明该解释依据题意和影像空间关系确定。

## 3. 光学通道

- Band 1：Red。
- Band 2：Green。
- Band 3：Blue。
- Band 4：Auxiliary Band 4。

第四通道很可能是近红外，但TIFF元数据仅将其标记为额外通道。未获得官方说明前，论文不直接宣称其为NIR。

## 4. 空间与面积

- 训练数据像素尺度约0.00008333度。
- 单像素面积约74.78至75.39平方米。
- 中位像素面积约74.93平方米。
- 单张256×256切片面积约4.91平方千米。
- 西部主要区域位于UTM 49N范围。
- 东部主要区域位于UTM 50N范围。
- 横州市目标投影暂定EPSG:32649，必须在正式边界到达后核实。
- 横州市目标分辨率暂定10米。
- 区域评估网格暂定1 km等面积网格。

## 5. 元数据异常

以下标签的横向像素尺度元数据约有5%异常：

1038、1093、1148、1200、1250、1301、1352、1404、1455。

处理原则：

1. 原始文件不修改。
2. 训练按数组索引配对。
3. 处理副本继承对应光学影像的空间参考。
4. 上述9组必须人工叠加检查。
